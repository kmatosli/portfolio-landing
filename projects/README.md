Projects Roadmap

This portfolio represents a set of interconnected, production-oriented projects focused on building scalable data, analytics, and decision-support systems. Each project is designed to stand alone while also integrating into a broader analytics ecosystem.

🚧 In Progress

Portfolio Landing Site
The central hub for all projects, designed to present work clearly to employers and collaborators. This site documents project scope, architecture decisions, and live demos as they become available.

News → Market Signal Engine (MVP)
A structured pipeline that ingests news (starting with Reuters), classifies and tags content, and translates qualitative information into actionable market signals. The MVP focuses on repeatable ingestion, normalization, and auditable outputs.

🔜 Coming Next

Economic Decision Dashboard (MVP)
An automated macroeconomic dashboard built on reliable public data sources (e.g., FRED, OECD). The dashboard is designed around decision-making rather than exploration, with clear regime detection, trend summaries, and board-ready outputs.

Charting & Table Specifications Package
A reusable visualization specification framework developed first in R and mirrored in Python. The goal is consistent, publication-quality charts and tables across languages, outputs, and delivery formats (web, reports, presentations).
